# AI Video Supercut Generator

This project provides a complete, extensive codebase for an AI-powered application that generates "supercuts" from long-form videos based on a user's natural language query. It combines state-of-the-art open-source models for transcription, semantic search, narrative generation, and video editing into a single, cohesive web application.

The core innovation is the **Narrative Engine**, which uses a Large Language Model (LLM) to function as a documentary editor, arranging retrieved clips into a coherent and compelling story rather than just a chronological list.

### Core Architecture

The system is designed as a Python Flask web application with a job-based backend to handle long-running video processing tasks.

1.  **Video Ingestion**: Downloads the video from a given YouTube URL using `yt-dlp`.
2.  **Transcription**: Uses OpenAI's `Whisper` to generate a highly accurate transcript with word-level timestamps.[2]
3.  **Semantic Indexing**: Breaks the transcript into coherent chunks (sentences) and uses `sentence-transformers` to generate vector embeddings for each chunk.[3]
4.  **Semantic Search**: When a user provides a query, it's embedded using the same model, and a `FAISS` index is used to find the most semantically relevant clips from the video.[3]
5.  **Narrative Engine (The Core Innovation)**: The retrieved, relevant text chunks are passed to a powerful LLM. The LLM is prompted to act as a scriptwriter, selecting, reordering, and trimming the clips to construct a logical narrative that answers the user's query.[4, 5, 6]
6.  **Video Synthesis**: The narrative script generated by the LLM is used by `MoviePy` to programmatically cut the segments from the original video and stitch them together into the final supercut.[7, 8]
7.  **Web Interface**: A simple Flask and JavaScript frontend allows users to submit jobs, monitor progress, and view the final result.

### How to Run This Project

**1. Clone the Repository:**
```bash
git clone <repository_url>
cd ai-video-supercut-generator
```

**2. Set Up a Python Environment:**
It's highly recommended to use a virtual environment.
```bash
python -m venv venv
source venv/bin/activate  # On Windows use `venv\Scripts\activate`
```

**3. Install Dependencies:**
This project requires `ffmpeg` for video processing. Ensure it's installed on your system and accessible in your PATH.
- **On macOS:** `brew install ffmpeg`
- **On Ubuntu/Debian:** `sudo apt update && sudo apt install ffmpeg`
- **On Windows:** Download from the official site and add to your system's PATH.

Then, install the Python packages:
```bash
pip install -r requirements.txt
```

**4. Set Up Environment Variables (for the Narrative Engine):**
The Narrative Engine uses a Hugging Face model. To access more powerful models, you might need an API key. Create a `.env` file in the root directory and add your key if needed.
```
#.env file
HUGGINGFACE_API_KEY="your_hf_api_key_here" 
```

**5. Run the Application:**
```bash
flask run
```
Navigate to `http://127.0.0.1:5000` in your web browser.
